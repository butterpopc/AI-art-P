## 아카라이브 접근 결과

- [AI 그림 채널 목록](https://arca.live/b/aiart): HTTP 200. 2026-10-23 게시글과 V5 관련 제목을 확인했다.
- `V5` 검색 페이지: HTTP 503과 전산 점검 안내.
- 목록에서 확인한 공지·V5 글의 개별 URL 4개: HTTP 429. 본문은 읽지 못했다. 제한을 우회하거나 반복 요청하지 않았다.
- 목록에 표시된 공지 제목에는 2026-08-21·2026-08-26 수정 표기가 있었다. 제목의 수정 표기만으로 본문의 V5 적합성·정확성을 인정하지 않는다.

따라서 채널의 존재·최근 활동은 확인했으나, 특정 아카라이브 가이드를 검증된 V5 제작법으로 채택한 상태는 아니다. 로그인/전화 인증이 필요하다는 응답도 아니므로 사용자 인증을 요청하지 않는다.

## 커뮤니티 글을 채택하는 조건

1. 제목뿐 아니라 본문·이미지 메타데이터에 V5 Full인지 명시되어 있는가?
2. 최초 작성일과 최종 수정일이 확인되고, 업데이트된 내용이 구분되는가?
3. 긍정·부정 프롬프트, 모델, 시드, 크기, sampler, steps, guidance, 후처리·참조 여부가 공개되는가?
4. 조건을 고정한 비교 이미지와 실패 예시가 있는가? 한 장의 예쁜 결과만으로 일반화하지 않는가?
5. V3의 태그 순서·SDXL/ComfyUI의 LoRA 문법·V4.5 참조 기능을 V5 설명에 섞지 않았는가?
6. 실제로 따라 했을 때 동일한 경향이 보이는가? 강한 가중치·긴 품질 태그 묶음을 이유 없이 필수라고 주장하지 않는가?

V5 명시+재현 설정+통제 비교가 있는 글을 실험 후보로 채택한다. 다운로드 프로그램은 필요성이 확인된 경우에만 출처·라이선스·동작을 검토하고 설치한다.

## 작가 태그: 확인된 사실과 후보

공식 V5 FAQ는 태그 프롬프팅이 계속 유효하다고 설명한다. 이것은 모든 개별 작가 태그가 충분히 학습되었거나 정확히 작동한다는 보장은 아니다. 이번 읽기 전용 자동완성 조회에서는 아래 후보들의 기대한 정확한 작가 태그 응답을 확인하지 못했다. 따라서 자동완성으로 V5 학습 여부를 검증했다고 주장하지 않는다. 또한 요청에 넣은 V5 API 모델 문자열의 정확한 공식 매핑은 생성 전에 별도 확인해야 한다.

아래 작가 식별명은 Danbooru 공개 작가 디렉터리에서 실재 표기를 확인했다. Danbooru의 등록 여부·태그 수는 NovelAI의 학습 데이터나 효과를 증명하지 않는다. 장점은 초기 선별을 위한 미술적 판단이며, 이번 세션에서 각 작가의 원본 작품을 새로 일괄 대조·분석한 결과는 아니다. 참고 3·6·7번의 작가는 아직 확인되지 않았다.

다섯 태그를 모두 섞지 않는다. 원본 작품과 클라이언트 선호를 먼저 대조하고, 얼굴·선 역할에 맞는 주 후보 하나와 색 표현 보조 하나만 남긴다. 처음에는 작가 태그 없는 기준과 개별 후보를 동일 조건으로 비교한다. 제시한 `artist:` 표기는 시험용이며 V5에서 작동 확인된 주문식이 아니다.

## V5 프롬프트 작성 원칙

성인 여성·구도 같은 기본 태그 + 얼굴·의상 구조를 설명하는 짧은 자연어 + 원하는 선/명암 표현을 조합한다. 이번 프로젝트는 영어로 기록하여 재현성을 우선한다. 품질 태그는 짧게 한 번만 사용하고, 스타일 비교 때는 자동 품질 태그의 영향을 통제한다. `high complexity`, `depthness`, `visual novel sprite` 등 V5 전용 태그는 역할이 맞을 때 개별 시험한다.

가중치는 기준 1.0부터 시작하고 결과가 약할 때 1.1~1.2처럼 소폭 조정한다. 강한 음수 가중치로 여러 문제를 동시에 지우거나, 작가 태그를 여러 개 무작정 누적하지 않는다. 작가 태그가 효과 없을 경우 가중치만 키우지 말고 구체적인 선·눈·색 묘사로 되돌아간다.

## 실제 V5 실행 후 확인

공개 웹앱과 PNG 응답으로 모델 ID를 확인했고, 여섯 장의 통제 비교를 완료했다. PUUZAKI 태그의 얼굴 표현 변화와 구조 이탈이 두 시드에서 재현됐다. saitom은 이번 조건에서 채택하지 않았다. 나머지 후보는 미시험이다. 공식 웹앱의 V5 표준 품질 접미사는 `very aesthetic, masterpiece, no text`이며, 이를 적용한 별도 한 장도 구조 오류가 남았다. [실제 비교와 한계](../reviews/v5-comparison.md)를 우선한다.
