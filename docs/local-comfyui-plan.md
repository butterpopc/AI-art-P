# 재사용 가능한 로컬 일러스트 제작 환경

공식 자료 확인 2026-10-23 (한국 시간).

- ComfyUI 공식 저장소: https://github.com/Comfy-Org/ComfyUI
- 공식 API 예제: https://github.com/Comfy-Org/ComfyUI/tree/master/script_examples
- API workflow export → POST /prompt → WebSocket /ws 또는 /history/{prompt_id}로 완료 확인 → /view로 산출물 회수.
- 현재 공식 README는 --offline으로 선택적 유료 API 노드를 비활성화하고 로컬 실행할 수 있다고 설명한다. 로컬 API와 유료 외부 서비스 API 노드를 구분한다.

현재 클라우드 세션은 nvidia-smi와 GPU 장치가 확인되지 않았고, CPU 5개, 메모리 약 33.3 GiB, 가용 디스크 약 29.8 GiB가 조회됐다. 호스트 노출 값이며 사용 가능한 실제 자원 한도·처리 속도를 보장하지 않는다. 사용자 PC 사양을 의미하지 않는다. 이 환경에 대형 모델을 내려받아 실용적인 GPU 생성 서버를 구축했다고 주장하지 않는다.

## 권장 구성

프로젝트별 브리프/참고 기록 → 프롬프트·시드·변경 가설 JSON → ComfyUI 작업 큐 → 애니 모델 기본 생성 → 육안 선별 → 필요 시 마스크 수정/포즈 제어 → 저강도 업스케일 → 원본·워크플로·모델 해시·결과 검수 기록 보존.

초기는 기본 노드 기반 생성/저장/API만 구축하고 한 장으로 연결을 검증한다. 다음으로 업스케일을 추가하고 동일성 보존 여부를 검수한다. ControlNet·참조 어댑터·LoRA는 선택 모델 계열과 호환되는 것만 도입한다. 사용자 지정 노드는 필요한 기능만 출처·라이선스·버전을 기록해 설치한다. 모델 라이선스도 커미션·상업 활용 허용 범위를 별도 확인한다.

하드웨어별 경험적 출발점(보장 사양 아님): NVIDIA VRAM 8 GB는 최적화와 타일 처리로 제한적 SDXL 작업, 12~16 GB는 SDXL 계열 애니 제작의 현실적인 시작점, 24 GB 이상은 여러 제어 모델·고해상도 처리 여유. 신형 대형 모델은 다른 조건이 필요할 수 있다. 시스템 RAM 32 GB 이상, 여러 모델 보관에 SSD 100 GB 이상 여유를 권장한다. 정확한 모델과 설치 방법은 실제 OS/GPU/VRAM을 확인한 뒤 결정한다.

GPT 기획을 현재 채팅에서 수행하는 반자동 구성은 별도 OpenAI API 호출 없이 시작 가능하다. 무인 프로그램에서 GPT를 직접 호출하려면 별도 API 인증·요금 조건을 확인해야 하며 ChatGPT 구독에 포함된 것으로 가정하지 않는다. 완전 로컬 기획 모델은 별도 대안이다.

로컬 이미지 생성에는 NAI의 Anlas가 들지 않지만 GPU·전력·저장 공간·실행 시간이 든다. 기존 장비가 없다면 새 장비 구매나 GPU 클라우드는 사용자의 '새 결제 없음' 조건을 자동으로 만족하지 않는다. 무료 도구라는 이유로 무한 처리량·무조건 고품질을 보장하지 않는다. 업스케일은 얼굴의 정체성이나 잘못된 구조를 자동으로 해결하지 않는다.

다음 필수 정보: 실행할 사용자 장비의 OS, GPU 정확한 모델 및 VRAM, RAM, 여유 저장 공간. 본 클라우드에서 개인 PC의 localhost에 직접 접근할 수 있다고 가정하지 않는다. 로컬 에이전트가 있으면 설치·테스트를 수행하고, 없으면 검토 가능한 설치 묶음과 작업 실행기를 전달한다.
