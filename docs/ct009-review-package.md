## 판정

- original-expressions-v2.png의 세 칸 모두 머리 꼭대기 위에 배경 여백이 있다. 기존 선호 시트로 단발의 전체 형태와 표정을 검토할 수 있다.
- original-head-angles-v1.png도 세 방향 모두 머리 위 여백이 있다. 좌우 가장자리의 일부 머리선/옷 크롭과 정확한 정투영 미검증은 별개 한계다.
- 원본 얼굴 및 CT-008의 상단 크롭은 기존대로 보존한다. 검토용 전체 머리 형태는 위 시트에서 확인할 수 있으므로, 현재 목적에 추가 여백 생성은 불필요하다.

**CT-009 완료: 기존 시트 재사용, 새 생성 0회.** 독립 초상 자체의 상단 복원이 필요한 별도 용도가 생기기 전에는 같은 이유로 생성하지 않는다.

## 작성한 결과물

작업공간의 delivery/ct009-face-review.html에 다음 4개 PNG 원본 바이트를 내장했다. 파일 하나를 내려받아 인터넷 없이 열 수 있다. 이 HTML은 로컬 전달용이며 GitHub에는 업로드하지 않았다. 기존 공개 face-review-v4.html은 변경하지 않았다.

1. 기준 얼굴 original-face-gpt-v2.png
2. CT-008 후보 original-face-gpt-neutral-v1.png
3. 기존 표정 original-expressions-v2.png
4. 기존 방향 original-head-angles-v1.png

화면은 미소/차분함 비교, 표정 시트, 방향 시트로 나뉜다. 원본/CT-008은 같은 1199×1312 해상도이고 배율 슬라이더를 함께 적용한다. 시트도 원본을 그대로 내장했다. 외부 참고/인증정보/개인 대화는 포함하지 않았다.

별도 delivery/ct009-face-review.manifest.json에 입력 4장의 SHA256·크기와 HTML SHA256을 기록했다. 내장 이미지를 다시 디코딩해 4장 모두 원본 해시와 일치하는지 확인했다. 외부 네트워크 요청·추적 기능은 없다. 브라우저별 실제 화면 동작 검증은 아직 수행하지 않았다.
