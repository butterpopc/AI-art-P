# CT-008 · GPT 작은 표정 편집 1장

2026-10-24 KST. 최신 사용자 지시(2026-10-24): Anlas는 가능한 적게 사용하되 img2img를 진행하며 GPT 이미지 도구와 ComfyUI도 선택할 수 있다. 이전 절대 0 차감 조건을 비용 최소화로 갱신한다. 새 결제나 무제한 소비 허용은 아니다. 이번 CT-008은 GPT 편집 1회로 NAI Anlas를 사용하지 않았다.

## 실제 실행

- 입력: [기준 얼굴](../artwork/original-face-gpt-v2.png).
- 도구: GPT 이미지 생성·편집 도구(image_gen). 입력 이미지 1개를 referenced_image_paths로 전달해 1회 편집했다. 별도 모델 버전·seed·strength·steps는 이 도구에서 노출되지 않아 기록하지 않는다.
- 변경 목적: 눈·머리·얼굴 비율·옷·조명을 유지하고 미소만 줄인 차분한 표정.
- 차이: 기존 GPT 표정 시트와 달리 단일 원본 구도에서 입의 작은 변화만 요청했다. 기존 ComfyUI 보존 시험과는 도구가 달라 공정한 모델 성능 비교로 취급하지 않는다.
- 결과: 작업공간의 artwork/original-face-gpt-neutral-v1.png. 원본 생성 파일도 별도 보존했다. 이 PNG는 현재 로컬 및 채팅 결과로 제공되며 GitHub에는 아직 업로드하지 않았다.
- 출력 SHA256: 8774cd1f758fa1eb9afba4bf7cc2c3b26fa4449e06395ca6dfb866f4b1a0c49d.
- 비용: NovelAI 호출 없음, NAI Anlas 사용 없음. GPT 도구의 별도 사용량/청구 수치는 반환되지 않았으므로 전체 무료라고 단정하지 않는다.

| 머리 | 적갈색 단발의 큰 갈래와 끝, 넓은 하이라이트와 어두운 층 유지 | 유지 양호 |

원본과 출력 둘 다 직접 확인했다. 픽셀 단위 동일성을 검증한 것은 아니다. **작은 입 표정 편집 후보로 통과**, 클라이언트 승인 전이며 기준 얼굴은 교체하지 않는다. 생성은 1회에서 종료했다.

## CT-006 전달 요약 수신 후 동일 배율 대조 · 2026-10-24

컨트롤 타워가 원본과 CT-008 PNG를 각각 원래 크기 1199×1312로 직접 열어 비교했다. 확대/축소 비율 차이 없이 전체 구도와 얼굴을 대조했다. 새 생성이나 이미지 수정은 하지 않았다.

- 원본의 올라간 입꼬리가 후보에서 거의 수평으로 바뀌어 미소/차분함 차이는 읽힌다.
- 눈꺼풀·눈썹 변화가 작아 강한 집중/엄격함 같은 감정 차이까지 검증한 것은 아니다. 이는 입만 바꾼 시험의 범위와 일치한다.
- 호박색 홍채·굵은 윗눈선·작은 코·성인 턱선·적갈 단발과 주요 머리 명암·따뜻한 피부 색 변화·목 그림자는 육안상 이어진다. 픽셀 동일성은 주장하지 않는다.
- 두 이미지 모두 머리 위가 잘려 있다. 기존 크롭 유지 지시를 따른 결과이며, 이번 표정 시험의 실패로 계산하지 않는다. 검토용 구도 개선 과제로 분리한다.

**최종 기술 판정: 작은 표정 편집 후보로 통과.** 강한 감정/새 포즈/다방향 동일성은 미검증. 원본 마스터 유지, 후보는 차분한 표정의 비교 자료로 보존하며 클라이언트 승인은 아직 없다.

외부 CT-006 담당의 결론은 사용자가 전달한 요약으로 수신했다. 해당 세션의 보고서 파일은 이 작업공간에 없어 원문·작가 출처 전체를 검증하지 않았다. [전달 요약과 확인 범위](ct006-handoff-summary.md)를 구분해 기록한다.

다음 작업 하나(CT-009 제안): 기준 얼굴 원본에서 머리 위 여백만 보완한 검토용 구도 1장. 기존 이미지를 단순 축소해도 잘린 머리는 복원되지 않으므로 이미지 편집이 필요하다. 표정·의상·배색을 동시에 바꾸지 않으며, 얼굴/명암을 유지하지 못하면 원본을 유지한다. 아직 실행하지 않았다.

후속 자료 갱신: [CT-006 전체 원문](ct006-reference-review.md)을 첨부로 확보해 읽었다. 위 원문 미확보는 당시 상태다. 이 보고서가 제안한 동일 배율 대조는 이미 완료됐으며 다시 생성하지 않는다. 다음 여백 보완은 기존 시트의 충족 여부를 먼저 확인한다.
