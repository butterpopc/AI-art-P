# 프로젝트 목표와 실행 계획

갱신: 2026-10-24 KST. 현재 계획을 기준으로 정리했다. 과거 제안·시험은 [시험 목록](experiments.md)과 개별 검수에 보존한다.

## 최종 목표

호평받은 성인 여성 캐릭터의 얼굴·적갈 단발·호박 눈·명암을 유지한 설정화 검토 자료를 완성한다. 3D 모델·리깅·분리 레이어는 이번 범위에 없다.

## 확정한 마무리 범위 · 2026-10-24

사용자는 전신·손 검수 이후 캐릭터 설정화 느낌의 전후좌우, 살색 베이스, 속옷 버전까지 제작하고 종료하도록 범위를 정했다. 각 버전은 같은 성인 캐릭터의 정면·후면·캐릭터 기준 왼쪽·오른쪽 4방향으로 구성한다.

| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 1 · CT-010 | 기존 정면 전신의 손·의상 연결 검수 및 필요한 부분만 보완 | 손가락·손목 연결·소매·셔츠/치마/부츠 접합에서 확인 가능한 결함을 점검. 가려진 부분은 미확인으로 기록 |
| 2 | 현재 의상 전후좌우 설정화 | 적갈 단발·호박 눈·성인 얼굴/체형 유지. 머리·어깨·허리·골반·무릎·발 높이를 대조하고 손/발 잘림 없이 배치 |
| 3 | 살색 베이스 전후좌우 | 체형 확인용 불투명한 무늬 없는 살색 바디슈트처럼 처리. 유두·성기·항문·민감 부위 세부나 윤곽 묘사 없음. 기존 비율 유지 |
| 4 | 속옷 전후좌우 | 기본 불투명 브라·브리프, 비침과 민감 부위 노출 없음. 성인 체형·얼굴·방향별 비율 유지 |
| 5 | 최종 묶음과 인계 | 선정본·실제 설정·검수·미해결 한계 정리 후 종료 |

공통 형식은 중립적인 서 있는 자세, 팔을 몸에서 조금 떨어뜨린 편한 자세, 단순한 배경과 같은 조명이다. 좌우는 캐릭터 기준으로 표기한다. 비대칭 단발을 단순 좌우 반전으로 대체하지 않는다. 후면처럼 새로 정해야 하는 의상 연결은 기존 정면을 바탕으로 최소한으로 설계하고 제작자 보완임을 표시한다.

손·의상 수정 후 전신을 기준으로 삼고 순서대로 진행한다. 필요가 확인된 수정만 하며 같은 결과를 반복 생성하지 않는다. 설정화 느낌의 시각 자료이며 정투영 치수·3D 제작 정확성을 검증 없이 주장하지 않는다.

**종료선:** 위 범위가 충족되면 추가 표정·의상·배경·포즈·작가 조사·도구 비교로 확장하지 않는다. 새 범위는 사용자가 별도로 요청할 때만 추가한다.

## 이미 완료한 일

- 기존 프로젝트 시안 선호 6장과 추가 참고 19장 구분, 인계/중복 자료 정리 완료.
- [CT-006 원문](ct006-reference-review.md) 확보·검토 완료. 작가 원작 이미지 접근 한계는 보고서대로 유지.
- [CT-008](ct008-gpt-edit-review.md) GPT 작은 표정 편집 완료 및 사용자 검토 통과. 차분한 표정 후보 유지, 원본 마스터 보존.
- [CT-009](ct009-review-package.md) 기존 시트의 머리 여백 충족 확인 및 오프라인 비교본 완료. 같은 여백·표정 시험은 반복하지 않음.

## 제작과 비용

- 사용자 최신 지시에 따라 Anlas 사용을 최소화하고 NovelAI·GPT 이미지 도구·ComfyUI 중 적합한 경로를 선택한다. 기존 절대 0 차감 조건은 현재 정책이 아니다. 새 결제·무제한 소비는 허용되지 않았다.
- GPT 1회 편집은 실제 성공 사례다. NAI 과거 구독 조회 401은 기록으로 남기고, 새 인증정보 보관을 실제 인증 성공으로 취급하지 않는다. 인증정보는 공개 저장소에 기록하지 않는다.
- 단계마다 얼굴·머리·비율·명암·손/발·의상 연결을 직접 확인한다. 검수 결과와 생성 설정을 남긴다. 비용 0만으로 시험을 늘리지 않는다.
- 사용자 통과, 클라이언트 선호, 제작자 보완, 기술 검수를 구분한다. 기존 전신 호평을 모든 의상 접합의 최종 승인으로 확대하지 않는다.

## 역할과 인계

실제 현재 작업·담당은 [README 지휘판](../README.md)에 하나만 둔다. 컨트롤 타워는 순서와 채택을 관리하고, 작업 세션은 배정 범위만 수행한다. 새 요청이 현재 범위와 관계없으면 대기에 기록한다.

시작할 때 최신 원격 README → 이 계획 → [현재 상태](status.md) → [시험 목록](experiments.md)을 확인한다. 로컬 변경을 강제 초기화하지 않는다. 종료 시 완료한 일·결과 위치·판정/한계·다음 행동 하나를 기록한다. 다른 세션의 파일은 자동 동기화된다고 가정하지 않는다.
