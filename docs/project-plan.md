# 프로젝트 목표와 실행 계획

갱신: 2026-10-24 · 한국 시간

## 최종 목표

클라이언트가 선호한 얼굴과 작화의 매력을 유지하면서, **표정·방향·전신이 같은 인물로 이어지는 현대 배경 게임용 성인 여성 캐릭터 검토 자료**를 만든다. 각 결과의 원본·실제 설정·검수·피드백을 함께 남겨 다음 세션이 이어서 작업할 수 있게 한다.

이 단계의 결과물은 캐릭터 디자인 검토 자료다. 3D 모델·리깅·분리 레이어 제작은 별도 범위다.

## 최신 실행 결정

최신 사용자 지시(2026-10-24): Anlas는 가능한 적게 사용하되 img2img를 진행하며 GPT 이미지 도구와 ComfyUI도 선택할 수 있다. 이전 절대 0 차감 조건을 비용 최소화로 갱신한다. 새 결제나 무제한 소비 허용은 아니다. 이번 CT-008은 GPT 편집 1회로 NAI Anlas를 사용하지 않았다.

[CT-008](ct008-gpt-edit-review.md)에서 GPT 단일 표정 편집 1장을 완료했다. NAI 무료 조건 미충족이라는 CT-007 사실은 유지하지만, 이전 0 차감 정책만으로 모든 유료 경로를 영구 제외하지 않는다. 인증과 실제 예상 비용 확인은 여전히 필요하다.

## 현재 확정한 근거

- 클라이언트는 이미지 모음의 **1·4·5·6·7·8번**을 선호했다. [번호와 파일 대응](brief.md#2026-10-24-클라이언트-선호-번호-확정)이 기준이다.
- 적갈색 기준 얼굴, 표정 두 버전, 얼굴 방향, 정면 전신이 선호 목록에 포함됐다. 은발 얼굴은 작화 비교 근거로 사용하며, 머리색을 다시 은발로 바꾸라는 지시로 해석하지 않는다.
- 선호는 해당 이미지의 호평이다. 체형·의상 세부와 모든 방향의 최종 승인은 별도로 확인한다.
- NovelAI·GPT 이미지 도구·ComfyUI 중 비용과 품질에 맞춰 선택한다. 도구 선택과 실제 품질 판정은 구분하고, 기존 GPT 기준 얼굴보다 나빠진 결과를 채택하지 않는다.
- 추가 결제 없이 **Anlas 사용 최소화** 조건을 적용한다. 과거 무차감 결과만으로 현재 기능의 비용을 보장하지 않는다.
- 사용자가 원본 기반 img2img와 GPT/ComfyUI 대안을 직접 요청했다. 이번에는 기준 얼굴 1장을 GPT 편집에 사용했다. 관련 없는 다른 참고의 외부 전송까지 확대하지 않는다.
- NovelAI 인증 자료는 사용자 Google Drive에 있다. 2026-10-24 파일 메타데이터만 확인했으며 키의 유효성과 현재 구독은 아직 검증하지 않았다. 키 값·개인 파일 링크는 공개 저장소에 남기지 않고 실행 시 보안 환경변수로 사용한다.

추가 근거: [2026-10-24 클라이언트 참고 15장·프롬프트 6개](../references/client-20261024/README.md). 기존 시안 선호 6장과 별개이며, 현재는 출처/텍스트 확인과 정리까지 완료했다. 이미지 육안 검토 전에는 새 공통 작화 기준을 확정하지 않는다.

인증 보완: 이번 환경 조회에서 NOVELAI_API_TOKEN 바인딩 ready를 확인했다. 실제 API 인증·구독·0 차감은 미검증이다. 키를 다시 요청하거나 Drive에서 불필요하게 복사하지 않는다.

## 단계별 계획

| 단계 | 목표와 산출물 | 완료 조건 | 상태 |

| 0. 기록 정리 | 지휘판, 완료 시험 목록, 인계 실물 검증, 중복 파일 정리 | 원본과 실패 근거를 보존하고 현재 자료를 찾을 수 있음 | 완료 |
| 1. 선호 기준 정리 | 선호 6장의 공통점·미확정 요소·다음 시험 1개 | 실제 이미지 근거와 제작자 해석을 구분하고 기존 실패와 다른 가설·판정 조건을 명시 | 기존 6장 CT-003 완료 · 추가 참고 CT-006 검토 대기 |
| 2. 제작 방식 검증 | 기준 얼굴을 유지하는 단일 소규모 시험과 검수 | 실행 범위·비용 최소화 조건 확인, 실제 결과가 정한 기준 통과. 실패하면 원인과 중단 지점을 남김 | CT-008 GPT 작은 표정 편집 완료 · 사용자/CT-006 대조 대기 |
| 3. 필요한 변형 확장 | 같은 얼굴의 표정, 방향, 필요한 전신 수정 | 한 번에 한 변경만 진행. 기존 선호 이미지로 충족한 항목은 재제작하지 않음. 동일성과 구조 확인 | 단계 2 통과 후 |
| 4. 검토본 정리 | 선정 이미지, 미확정 질문, 설정·검수 기록 | 미선정 시험과 선정본을 명확히 구분하고 클라이언트 확인 사항을 최소화 | 단계 3 결과에 따라 |

## 품질 판정

1. **얼굴:** 눈매·코와 입의 간결함·성인 인상·얼굴 비율이 기준과 이어지는가.
2. **작화:** 눈선과 색선, 머리 명암, 피부 색 변화가 선호 이미지의 매력을 유지하는가. 긴 코·평면적 피부 등 기존 실패가 재발하지 않는가.
3. **변형 목적:** 요청한 표정이나 방향의 차이는 읽히면서, 바꾸지 않은 머리·눈·의상은 유지되는가.
4. **구조:** 크롭, 손, 좌우 연결, 의상 형태 등 해당 이미지에서 필요한 항목을 실제로 확인했는가. 정투영·3D용 정확성은 검증 없이 주장하지 않는다.
5. **재현과 비용:** 입력·모델·프롬프트·시드·설정·파일 위치·비용 관측이 남아 있는가.

구체적인 시험별 통과·중단 기준은 [CT-003 검토 결과](ct003-design-review.md)에 정했다. 당시 다음 후보는 준비된 V5 일반 img2img 보존 1장이었으나, [CT-007 점검](ct007-nai-readiness.md)에서 현재 0 차감 조건 미충족으로 실행 대상에서 제외했다. CT-008 GPT 후보와 CT-006 외부 보고를 통합한 뒤 현재 비용 조건에 맞는 다음 행동 하나를 설계한다. 이전 실패 시험이나 인증 실패 조회를 자동 반복하지 않는다. 예쁜 이미지 한 장이나 비용 0이라는 이유만으로 다음 장수를 늘리지 않는다.

## 세션별 역할

- **컨트롤 타워:** 우선순위와 한 번에 할 일 하나를 결정하고, 작업 에이전트에 구체적인 명령을 전달한다. 결과를 검토한 뒤 다음 단계와 GitHub 지휘판을 갱신한다.
- **작업 에이전트:** 배정된 작업과 파일 범위에서 실행하고, 근거·결과·남은 장애를 컨트롤 타워에 보고한다. 다른 작업을 임의로 시작하거나 사용자에게 같은 프로젝트 설명을 다시 요구하지 않는다.
- **사용자:** 클라이언트 피드백과 사용자만 결정할 수 있는 취향·권한을 전달한다. 기술 설정·자료 탐색·기록 정리는 에이전트가 처리한다.

실제 담당·시각·진행 상태는 [README 지휘판](../README.md#ai-세션-지휘판) 한 곳에서 관리한다. 이 계획의 단계 상태는 그 배정을 설명하며 별도 담당을 만들지 않는다. 내부 작업 에이전트의 결과는 부모 컨트롤 타워가 검토하고 게시한다.

## 재시작과 종료 규칙

- 시작할 때 최신 README → 이 계획 → [현재 상태](status.md) → [시험 목록](experiments.md)을 확인한다.
- 이미 수행한 작업은 다시 실행하기 전에 바뀐 변수와 이유를 명시한다. 접근할 수 없는 과거 자료는 미확인으로 기록하고 무한히 재탐색하지 않는다.
- 새 지시가 오면 현재 목표와의 관계를 판단한다. 사용자가 전환을 지시하면 중단 지점을 남기고 전환한다.
- 종료 보고는 `완료한 일 / 결과 위치 / 판정과 장애 / 다음 행동 하나`로 남긴다. 지휘판·현재 상태·시험 목록에는 각 역할에 맞는 정보만 기록한다.
- 다른 채팅과 로컬 작업공간은 자동 동기화되지 않는다. 최신 원격과 실제 파일 확인을 통해 인계한다.

## CT-006 요약 수신 및 CT-008 대조 후 결정

외부 검수 [완료 요약](ct006-handoff-summary.md)을 수신했다. 전체 원문과 작가 출처는 아직 이 환경에서 확인하지 못했다. CT-008은 원본과 동일 배율로 직접 비교해 작은 표정 편집으로 통과했다. 강한 감정/새 방향 성공으로 확대하지 않는다. 다음 CT-009는 검토용 머리 위 여백만 보완하는 1장으로 계획하고, 표정·의상·배색은 유지한다. 생성은 아직 하지 않았다.

## CT-006 원문 및 추가 선호 4장 반영

[CT-006 전체 보고서](ct006-reference-review.md)를 확보해 읽었다. 과거 원문 미확보 기록은 해소됐고 CT-008 동일 배율 검수도 완료됐다. 작가 원작 이미지 접근 한계를 확인 완료로 바꾸지 않는다. 사용자 확인으로 [새 참고 4장](client-addition-20261024.md)도 선호 자료에 추가했다. 기존 추가 15장과 합쳐 19장, 기존 우리 시안 선호 6장은 별개다. 현재 얼굴 유지 판단은 유지한다. CT-009 여백 보완은 기존 시트로 목적을 충족하는지 확인한 뒤 필요할 때만 실행한다.

## CT-009 종료

[기존 여백 검수 및 검토본](ct009-review-package.md) 완료. 표정 시트 v2와 방향 시트가 머리 위 여백을 이미 충족해 재생성하지 않았다. 원본·CT-008·표정·방향을 내장한 오프라인 HTML을 로컬 전달용으로 작성했다. 검토 자료 준비까지 완료했으며, 클라이언트 최종 승인·전신 세부 구조 검증은 여전히 별개다.
