# 현재 상태와 다음 행동

갱신: 2026-10-24 · 한국 시간. 이 문서는 작업 재개의 시작점입니다. 이전 문서와 충돌하면 이후 사용자 지시와 이곳에 기록한 근거를 확인합니다.

## 유지할 방향

- 현대 배경의 명백한 성인 여성 히로인.
- 적갈색 단발·호박색 눈의 [기준 얼굴](../artwork/original-face-gpt-v2.png)과 정면 인상에 호평을 전달받음.
- 호평 범위는 얼굴·정면 인상. 체형·의상·측면·전체 표정 승인은 아님.
- NovelAI 주력, ComfyUI 보조. 기준 얼굴은 비교 자료로 보존.
- 추가 결제 없음. 이후 사용자 지시에 따라 추가 Anlas 차감 0 조건 우선. 과거 유료 시험 예산을 현재 소비 허가로 사용하지 않음.

## 진행 하나

**별도 작업공간의 V4.5 시험·조사 기록 대조.**

GitHub의 완료 시험과 최근 채팅 보고는 [시험 목록](experiments.md)에 정리했습니다. 인계 ZIP의 로컬 V5 3장·ComfyUI 후보는 [실물 검증 완료](handoff-evidence-20261024.md)입니다. 다음 행동은 별도 작업공간의 V4.5 무차감 1장·커뮤니티 조사 파일을 기존 채팅의 저장 위치와 대조하는 것입니다. 확인할 수 없다면 미확인으로 남기고 같은 작업을 재실행하지 않습니다. 사용자에게 같은 프로젝트 설명을 다시 요구하지 않습니다.

완료 조건: 기존 시험의 모델·입력·시드·설정·결과 위치를 확인하거나 확인 불가로 표시하고, 다음 제작 가설 하나와 판정 기준을 정합니다.

## 이미 완료한 범위

- GitHub: 기존 시안, 새 얼굴·표정·방향·정면 전신 후보, V5 비교와 검수·비용 기록 보존.
- GitHub와 최근 채팅의 중복·불일치 목록 작성.
- README·문서 안내·시험 목록을 현재/과거 상태별로 정리.
- 이번 정리는 이미지 생성이나 과거 결과 재검수가 아님.

| 항목 | 재개 조건 |

| 새 얼굴 유지 시험 | 기존 결과 대조 후, 새로운 가설과 0 차감 조건 확인 |
| 체형·의상·후면 확장 | 현재 기준과 검토 범위를 정한 뒤 한 항목씩 |
| 작가 태그·도구 추가 조사 | 다음 시험을 막는 구체적인 질문이 있을 때 |

## 남은 확인과 기록 차이

- 로컬 정사각형 V5 3장·ComfyUI 표정 후보는 인계 ZIP에서 실물을 확인하고 해시·PNG 무결성을 검증함. 이미지 원본은 ZIP에 보존하고 GitHub에는 검증 요약을 반영함. 별도 작업공간의 V4.5 무차감 1장·커뮤니티 보고서는 여전히 채팅 보고와 실제 파일 대조 필요.
- ASK는 커뮤니티 조사에서 미시험 후보로 남아 있지만 로컬 V5 시험 보고가 있음. 모델·설정이 다를 수 있으므로 중복 여부를 조건별로 판정.
- 이전 문서의 “현재 선정본 네 장”은 과거 윤서린 패키지 설명. 현재 얼굴 후보와 혼동하지 않음.
- 얼굴 원본의 외부 서비스 전송 허용 질문이 로컬 채팅에 남아 있음. 저장소 정리 요청을 이미지 전송 허용으로 해석하지 않음.
- 채팅에서 보고된 비용은 당시 관측값. 현재 구독·잔액·서비스 정책을 실시간 확인한 것은 아님.

## 작업 전환과 인계

1. 이 문서와 시험 목록을 먼저 읽습니다.
2. 진행 항목은 하나만 둡니다. 새 아이디어는 대기에 적습니다.
3. 재시험 전에 기존 조건과 달라진 변수·이유를 적습니다.
4. 전환할 때 결과 파일, 판정, 남은 장애, 다음 행동을 갱신합니다.
5. 같은 조건의 실패를 이유 없이 반복하지 않습니다. 다른 채팅은 자동 동기화되지 않습니다.
