# 현재 상태와 다음 행동

갱신: 2026-10-24 · 한국 시간. 이 문서는 작업 재개의 시작점입니다. 이전 문서와 충돌하면 이후 사용자 지시와 이곳에 기록한 근거를 확인합니다.

배정·상태·담당의 기준은 [README의 AI 세션 지휘판](../README.md#ai-세션-지휘판)입니다. 아래는 현재 지시 CT-009의 상세 인계이며, 별도 작업을 배정하는 지시서가 아닙니다.

## 유지할 방향

- 현대 배경의 명백한 성인 여성 히로인.
- 적갈색 단발·호박색 눈의 [기준 얼굴](../artwork/original-face-gpt-v2.png)과 정면 인상에 호평을 전달받음.
- 호평 범위는 얼굴·정면 인상. 이후 표정·방향·정면 전신도 선호 목록에 포함됨. 체형·의상 세부와 측후면의 최종 승인은 아님.
- NovelAI·GPT 이미지 도구·ComfyUI 중 비용/품질에 맞춰 선택. 기준 얼굴 보존.
- 추가 결제 없음. 최신 지시는 Anlas 최소 사용 및 img2img 실행 허용. 과거 150 Anlas 예산은 자동 부활하지 않음.

## 다음 행동 하나 · 검토용 머리 위 여백 보완

최신 사용자 지시(2026-10-24): Anlas는 가능한 적게 사용하되 img2img를 진행하며 GPT 이미지 도구와 ComfyUI도 선택할 수 있다. 이전 절대 0 차감 조건을 비용 최소화로 갱신한다. 새 결제나 무제한 소비 허용은 아니다. 이번 CT-008은 GPT 편집 1회로 NAI Anlas를 사용하지 않았다.

[CT-008 결과](ct008-gpt-edit-review.md): 기준 얼굴을 GPT 이미지 도구에 입력해 미소만 줄인 후보 1장을 생성했다. 원본과 결과를 직접 확인했으며 얼굴/명암은 육안상 유지되고 입꼬리가 중립으로 바뀌었다. 기준 얼굴은 교체하지 않는다. 결과 PNG와 메타데이터는 로컬 artwork/original-face-gpt-neutral-v1.*에 보존했으며 PNG는 아직 GitHub에 업로드하지 않았다.

CT-006 완료 요약을 수신했고 [원문 접근 한계](ct006-handoff-summary.md)를 기록했다. CT-008 원본과 후보를 모두 1199×1312 원래 크기로 직접 대조해 작은 표정 편집으로 통과 판정했다. 다음 계획은 기준 얼굴의 머리 위 여백만 보완하는 1장이다. 현재는 계획 확정까지이며 새 생성은 하지 않았다. 기존 NAI 401은 해결하지 않았으며 비용 최소화 허용이 인증 문제를 해결한 것은 아니다. 이번에 NAI 구독 조회나 생성은 하지 않았다.

## 남은 확인과 기록 차이

- 새 클라이언트 평가(2026-10-24): 이번 채팅의 이미지 모음 3장 중 **1·4·5·6·7·8만 선호**. [번호와 파일 대응](brief.md#2026-10-24-클라이언트-선호-번호-확정)을 확정했다. 7번 정면 전신도 호평받음. 개별 세부의 최종 승인과는 구분한다. 선호에서 빠진 이미지도 중복 파일이 아니므로 원본을 유지한다.
- 로컬 정사각형 V5 3장·ComfyUI 표정 후보는 인계 ZIP에서 실물을 확인하고 해시·PNG 무결성을 검증함. 이미지 원본은 ZIP에 보존하고 GitHub에는 검증 요약을 반영함. 별도 작업공간의 V4.5 무차감 1장·커뮤니티 보고서는 여전히 채팅 보고와 실제 파일 대조 필요.
- ASK는 커뮤니티 조사에서 미시험 후보로 남아 있지만 로컬 V5 시험 보고가 있음. 모델·설정이 다를 수 있으므로 중복 여부를 조건별로 판정.
- 이전 문서의 “현재 선정본 네 장”은 과거 윤서린 패키지 설명. 현재 얼굴 후보와 혼동하지 않음.
- 얼굴 원본의 외부 서비스 전송 허용 질문이 로컬 채팅에 남아 있음. 저장소 정리 요청을 이미지 전송 허용으로 해석하지 않음.
- 채팅에서 보고된 비용은 당시 관측값. 현재 구독·잔액·서비스 정책을 실시간 확인한 것은 아님.
