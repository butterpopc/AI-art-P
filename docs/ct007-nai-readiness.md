# CT-007 · NAI 보존 시험 준비 점검

2026-10-24 KST. 사용자가 외부 이미지 검수와 병행할 다른 작업을 요청해 컨트롤 타워가 기술 준비만 점검했다. 새 이미지 생성·이미지 전송·결제 요청은 하지 않았다.

## 결론

**기존 V5 img2img 보존 1장은 현재 추가 Anlas 차감 0 조건에서 실행하지 않는다.** 공식 구독 안내의 무료 생성 조건에는 기본 이미지 미사용이 포함된다. 별도로 설정된 인증정보의 읽기 전용 조회는 HTTP 401로 실패했다. 준비 입력은 정상이나 실행 준비가 완료된 것은 아니다.

## 확인 결과

| 항목 | 근거와 판정 |
|---|---|
| 입력 무결성 | 인계 준비 PNG SHA256이 요청에 기록된 4860ce6fd183c7b3e997125b7241bc3dc65cf9aae783e5b7439b7b050dff3132와 일치 |
| 크기/장수 | 실제 PNG 960×1024, 요청 크기 일치, 983040픽셀, 1장 |
| 텍스트 구조 | 양/음성 프롬프트가 각각 v4 caption과 일치 |
| 이미지 필드 | 실제 base64가 아닌 경로/해시 자리표시자. 준비 JSON 그대로 제출 불가 |
| 환경 인증 바인딩 | 환경 도구는 NOVELAI_API_TOKEN ready로 보고. 토큰 값은 출력하지 않음 |
| 실제 인증 조회 | 설정된 환경변수로 기존 subscription 함수의 GET /user/subscription 1회 실행. HTTP 401. 자동 재시도 없음. 계정/구독 활성 상태 확인 실패 |
| 비용 | 공식 구독 문서의 Opus 무료 조건은 기본 이미지 미사용. 이 img2img 요청에 무료를 적용할 근거 없음. 유료 확인용 시험도 하지 않음 |
| 도구 지원 | tools/novelai.py는 V4.5 generate만 허용. tools/novelai_v5.py도 generate 요청을 구성하며 832×1216으로 결과를 검증함. 둘 다 준비된 V5 img2img용 실행기가 아님 |
| 과거 예산 코드 | V5 도구의 150 Anlas 한도/50 예약은 과거 유료 시험 로직. 현재 0 차감 정책을 강제하는 장치가 아님 |

입력 검사에 API 키는 필요 없었다. 실제 구독 조회에는 이미 설정된 환경변수만 사용했고 Drive 키를 복사하거나 개인 인증 파일을 탐색하지 않았다. HTTP 401은 이 실행 경로의 인증 실패이며, Drive 원본 키의 유효성이나 계정 만료를 단정하지 않는다.

## 공식 자료와 해석

- [NovelAI Subscription](https://docs.novelai.net/en/subscription/): 2026-10-24 조회. Opus의 Anlas 없는 생성 조건에 기본 이미지 미사용을 명시하고, V4.5보다 높은 모델에는 사용량 제한이 있다고 설명한다. 소형 이미지·23 steps·활성 Opus만으로 img2img 무료를 보장할 수 없다.
- [Image2Image](https://docs.novelai.net/en/image/controltools/): 기본 이미지를 출발점으로 사용하는 기능이다. 준비 요청의 action=img2img 및 image 입력은 이 경로에 해당한다.

정확한 유료 가격이나 실제 차감량을 계산·관측한 것은 아니다. 공식 설명과 맞지 않는 무료 가정을 폐기한 것이다. 과거 무료 텍스트 생성 기록은 당시 관측값으로 보존한다.

## 후속 결정

1. CT-003의 시각 기준은 유지한다. 그 문서의 img2img 시험은 당시 제안으로 보존하고 비용 조건 미충족 상태를 표시한다.
2. 외부 CT-006 보고서가 도착하면 기존 선호 기준과 대조한다. 그 결과를 바탕으로 현재 비용 조건을 만족하는 다음 행동 하나를 결정한다. 이전 실패와 같은 텍스트 생성이나 ComfyUI 시험을 자동 반복하지 않는다.
3. 인증을 다시 사용할 실제 필요가 생기면 환경 바인딩/서비스 인증 경로를 먼저 진단한다. 같은 설정으로 401 조회를 반복하거나 사용자에게 곧바로 키 재발급을 요구하지 않는다.
4. 유료 img2img 실행기 구현은 현재 범위에서 진행하지 않는다. 무료 여부가 해결되지 않은 상태에서 입력 이미지를 인코딩·전송하지 않는다.

검증: 준비 입력 해시·PNG 크기·프롬프트/caption 일치·장수·자리표시자 확인 통과. 생성 도구 코드는 변경하지 않았으므로 생성 테스트는 실행하지 않았다.
