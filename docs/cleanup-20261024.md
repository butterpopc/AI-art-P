## 남긴 것과 이유

- 후속 클라이언트 평가의 번호 대상은 확인 중입니다. 이번 삭제는 선호 번호에 근거한 이미지 삭제가 아니라, 내용 중복과 구형 보조 파일에 대한 정리입니다.
- 이미지 원본 27장 전부: 고유한 제작 결과·참조 관계·성공/실패 증거입니다. 그림이 미선정이라는 이유만으로 삭제하지 않았습니다.
- artwork JSON과 manifest: 실제 요청·입력 참조·시드·해시·검수를 보존합니다. 삭제한 V5 요청 사본 12개는 각각 이곳의 request와 JSON 객체 전체가 같습니다.
- reviews와 비용 원장: 같은 실패를 반복하지 않기 위한 근거입니다.
- references/manifest.json: 원본 참고는 비공개로 보관되므로 해시·출처 목록이 필요합니다.
- 텍스트 지시문·V4.5 입력 2개·실행 도구 3개·기존 테스트: 고유한 제작법·현재 도구의 기본값·모듈 의존성을 유지합니다. V5 도구는 앞으로 별도 동일 요청 사본을 쓰지 않도록 수정했습니다.
