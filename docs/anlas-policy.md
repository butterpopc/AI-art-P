# Opus / V5 비용 정책과 운영 기준

공식 웹 문서 직접 확인: 2026-10-23, 한국 시간. 확인일은 문서 수정일과 다르다. 사용자 지시: 0 Anlas 조건에서는 자율적으로 충분히 시험하고, 실제 Anlas도 불필요하게 낭비하지 않는 한 적극적으로 사용해도 된다. 새 결제는 허용되지 않았다.

## 공식 정책

- [V5 FAQ](https://docs.novelai.net/en/faq#opus-usage-limits): V5만 Opus 무료 생성 사용량 한도를 적용한다. V4.5 이하 모델은 기존 조건 내 무제한 생성 유지.
- [요금/구독 문서](https://docs.novelai.net/en/subscription), [V5 소개](https://novelai.net/v5): 한 번에 1장, 정상 해상도 범위(1024×1024 픽셀 규모까지), 28 steps 이하가 기본 무차감 조건. V5는 사용량 잔여가 필요하다. 현재 사용한 832×1216, 23 steps, 1장 텍스트 생성은 실제 무차감으로 확인했다. 최대 변 길이가 아니라 픽셀 규모와 실제 견적을 확인한다.
- FAQ: 기본 1MP·23 steps에서 월 약 7,000장, 한도 100%는 약 1,730장, 1%당 약 17장이라는 근사치. 해상도·steps에 따라 소비가 달라지므로 보장 수량이 아니다.
- 한도는 연속 충전되며 일/월 일괄 초기화가 아니다. 첫 30일 약 11%/일, 연속 구독 약 14%/일. 빈 상태에서 약 9일 또는 7일. 갱신 순간 즉시 충전되지 않는다. 중단 후 재구독의 세부 충전율은 FAQ 표를 따른다.
- 무료 한도 소진 후 Subscription/Paid Anlas를 사용해 계속 생성 가능. 고해상도·높은 steps처럼 Anlas를 지불하는 생성은 이 무료 사용량 한도 대상이 아니다.
- FAQ: medium effort는 사용량 및 Anlas를 약 42% 절약할 수 있다. 현재 Full 기본 모델과 결과가 달라질 수 있으므로 무통보로 동일 모델 취급하지 않는다.
- Opus의 Subscription Anlas는 10,000까지 매 갱신 때 보충된다. 잔여분에 10,000을 계속 더하는 구조가 아니다. Paid Anlas와 구분되며 구독분부터 사용된다. 갱신/만료 정책은 공식 구독 문서를 우선한다.
- [Precise Reference](https://docs.novelai.net/en/image/precisereference): 참조당 이미지 생성에 추가 5 Anlas. 기능/지원 모델을 별도 확인해야 하며 현재 V5에 그대로 적용하지 않는다.
- 이미지 입력, 참조, 편집, 확대 등은 모두 0 Anlas라고 가정하지 않는다. 해당 기능의 현행 비용과 요청 설정을 확인한다.

## 자료 간 주의점

구독 본문에는 정상 크기를 'at least Normal Sized'라고 표현한 구절이 있으나 같은 문서 각주와 V5 소개는 up to 1024×1024라고 명시한다. 고해상도 무료로 해석하지 않는다. [Steps 안내](https://docs.novelai.net/en/image/stepsguidance)의 무료 생성 설명에는 V5 한도 조건이 생략되어 있으므로 V5 전용 FAQ를 함께 적용한다.

## 프로젝트 운영

1. 0 Anlas 비교는 한 요소씩 바꾸는 3~4장 단위로 진행하고 육안 검수한다. 개선이 보이는 방향만 다음 묶음으로 이어 간다. 누적 장수 자체를 성과로 삼지 않는다.
2. Anlas를 쓰는 요청도 별도 허락 없이 진행 가능하다. 먼저 해결할 결함과 사용할 기능, 예상 비용을 기록하고 한 장의 효과부터 확인한다. 결과가 개선되면 확대한다. 사용자에게 기술 판단을 떠넘기지 않는다.
3. 기존 150 Anlas 시험 한도는 초기 내부 관리 기준으로 유지한다. 이는 사용자가 새로 정한 지출 상한이나 매번 승인받아야 한다는 뜻이 아니다. 범위 확대가 필요하면 관측 비용·잔액·개선 효과를 근거로 명시적으로 재설정한다.
4. 요청은 순차 실행하고 잔액 전후 차감을 원장에 기록한다. 오류 시 자동 재시도하지 않으며 비용 불명 요청은 대조 후 진행한다. 실제 도구의 현재 잔액 검사는 Subscription Anlas만 대상으로 한다. 이 검사를 전체 Paid 포함 잔액 검증이라고 주장하지 않는다.
5. 추가 구매·플랜 변경·자동 결제 설정은 하지 않는다. 잔여 Anlas가 만료될 수 있다는 이유로 불필요한 생성은 하지 않는다.

이번 정책 조사에는 이미지 생성이나 Anlas를 사용하지 않았다. 계정의 실시간 무료 사용량 바 잔여율은 이번 조사에서 조회하지 않았다.
