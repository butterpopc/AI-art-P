# 제작 계획 — V5 Full 기준으로 재정렬

> 최신 비용 운영: 사용자는 낭비하지 않는 한 기존 Anlas의 적극적 자율 사용을 허용했다. [정책 조사와 운영 기준](anlas-policy.md)을 우선한다. 아래 과거 실험 중단 판단은 당시 프롬프트에 관한 것이며 새로운 원본 기반 얼굴 실험까지 금지하는 뜻은 아니다.

기준일: 2026-10-23 (한국 시간). 기술 선택과 검수는 제작자가 담당하고, 사용자는 최종 검토 및 클라이언트 취향 확인을 담당한다.

## 현재 판단

GPT 이미지 도구는 캐릭터의 외형·구도·의상 구조를 정리하는 마스터 제작에 사용한다. NovelAI V5 Full은 애니풍 얼굴·선·색 표현을 탐색할 후보 도구다. 이름만으로 최종 품질 향상을 가정하지 않는다.

현재 마스터 및 선정 이미지 네 장은 `image_gen` 산출물이다. V4.5의 텍스트 생성 001은 머리핀 좌우·머리 길이·치마 구조가 달라졌고, 참조 생성 002는 얼굴과 배색을 더 유지했으나 A라인 치마가 몸에 붙는 형태로 변하고 손 디테일이 어색해졌다. 두 NovelAI 결과는 최종 전달본에서 제외한다. 두 시험은 프롬프트도 달랐으므로 참조 기능만의 효과를 분리한 엄밀한 실험은 아니다.

사용자가 V5 Full을 지정했다. V4.5 실험을 V5 품질의 근거로 쓰지 않는다. 현재 공식 V5 페이지는 Precise Reference와 Vibe Transfer가 V5에 아직 없다고 안내한다. 따라서 V4.5에서 성공한 참조 호출을 V5로 단순 변경하지 않는다.

## 순서

1. **자료 검증:** V5 공식 문서와 최신 커뮤니티 글에서 모델·작성/수정일·설정·원본 이미지 공개 여부를 확인한다. 접근 실패 자료는 읽었다고 기록하지 않는다.
2. **마스터 고정:** 성인 얼굴, 머리핀 좌우, 헤어 실루엣, 의상 구조와 배색을 고정한다. 일상복·이브닝은 별도 의상이다.
3. **V5 기준 프롬프트:** 작가 태그 없는 기준안부터 작성한다. 문장으로 구조를 지정하고, 확인된 태그로 표현을 보조한다. 자동 품질 태그와 직접 입력 품질 태그를 중복하지 않는다.
4. **최소 비교:** V5 지원 모델 ID·설정·비용 조건을 확인한 후, 같은 구도·시드·크기·샘플러로 기준안과 후보 작가 태그 한 개씩을 비교한다. 첫 비교는 기준 1장 + 가장 적합한 후보 2장 이내로 시작한다. 결과가 구분되지 않으면 늘리지 않는다.
5. **재현성 확인:** 승리 후보와 기준안을 두 번째 시드에서만 재검증한다. 작가 혼합은 단일 후보의 역할이 확인된 이후, 주 역할 1개와 보조 역할 1개까지 시험한다.
6. **마감:** 얼굴·구조 유지와 작화 개선이 함께 확인된 방식만 표정·설정화에 확대한다. V5에서 입력 이미지 편집 기능을 쓰려면 현재 지원 여부와 API를 먼저 확인한다. 검증되지 않은 기능은 계획의 필수 전제로 두지 않는다.

## 판정과 중단 기준

| 항목 | 통과 조건 | 탈락 예 |
|---|---|---|
| 인물 동일성 | 긴 눈매·머리 실루엣·성인 인상·식별 장식 유지 | 다른 얼굴, 머리핀 반전, 유아적인 인상 |
| 구조 | 손·의상·방향 연결이 원안과 일치 | A라인 치마가 펜슬/머메이드로 변함 |
| 표현 | 목표인 선명한 윗눈꺼풀·명료한 명암·섬세한 색선이 개선 | 단순 광택 증가, 채도만 상승, 얼굴이 둥글어짐 |
| 재현성 | 두 시드에서 같은 장점이 보임 | 한 장만 우연히 좋은 결과 |
| 효율 | 채택할 개선이 수정량과 비용에 비해 충분 | 다시 그려야 할 구조 결함이 늘어남 |

기술적 결함은 제작자가 판단한다. 작화의 선호·매력의 강도는 최종 선정안에서만 클라이언트에게 묻는다. 여러 변경을 한 번에 섞은 이미지는 원인 분석용 근거로 사용하지 않는다.

## 비용

추가 결제·Anlas 구매는 하지 않는다. 사용자는 기존 Anlas의 제한적 사용을 허용했다. 초기 시험 한도는 150 Anlas이며 목표 소비량이 아니다. 참조 시험 002의 확인된 차감은 5 Anlas다. 다음 유료 시험 전후 차감을 확인하고 `reviews/novelai-costs.json`에 기록한다. V5는 Opus에도 별도 사용량 한도가 있어 V4.5의 무제한 무료 조건을 적용하지 않는다.

최소 비교 5장과 품질 구간 비교 1장을 완료했다. 결과는 ../reviews/v5-comparison.md에 기록했다. 구조 이탈이 남아 현 조건의 반복 생성을 중단하고 기존 선정본을 유지한다.
