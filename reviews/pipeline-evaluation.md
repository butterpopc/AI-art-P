# GPT → NovelAI 분업 시험 기록

2026-10-23 · 검수자: 제작 에이전트 · 클라이언트 평가 전

| 결과 | 관찰 | 판단 |
|---|---|---|
| GPT 대표 이미지 v1 | 얼굴·일상복 배색·A라인 치마·두 줄 핀이 설계 의도와 대체로 일치 | 현재 마스터 유지 |
| NovelAI 001 / V4.5 Full text-to-image | 머리핀 좌우 반전, 머리 길이 축소, 치마 앞주름/실루엣 변경, 얼굴 인상 변경 | 전달 제외 |
| NovelAI 002 / V4.5 Full + GPT character reference | 얼굴·머리색·핀 위치는 더 가까움. 치마가 몸에 붙는 머메이드형으로 변하고 손 모양이 어색함. 기존보다 단순한 명암 | 전체 재생성 마감본으로 불채택 |

002의 참조 기능 차감은 전후 구독 Anlas 잔액 비교로 **5 Anlas** 확인했다. 원장에는 토큰·계정 연락처·전체 잔액을 넣지 않는다. 001과 002는 프롬프트도 다르므로 참조 기능만의 인과효과를 분리한 결과라고 주장하지 않는다.

분업 자체는 구조 설계와 작화 탐색을 나눈다는 점에서 유용하나, NovelAI가 자동으로 더 좋은 마감 도구가 된다는 결론은 얻지 못했다. GPT 마스터를 유지하고 V5 Full의 프롬프트를 별도 검증한다. 공식 V5 안내에서 현재 미제공인 참조 기능을 파이프라인의 필수 단계로 가정하지 않는다.

V5 Full 여섯 장의 실제 비교를 완료했다. [V5 검수](v5-comparison.md)에 별도 기록했으며 구조 오류로 기존 마스터를 유지한다. 이번 V5 추가 차감은 0 Anlas다.
