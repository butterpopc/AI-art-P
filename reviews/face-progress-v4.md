# 얼굴 제작 v4 진행 기록

NAI V5 Full 3장과 GPT 방향 시트 1장 제작. NAI는 같은 시드에서 CFG 7→5, 같은 CFG에서 프롬프트 블록 간소화, 마지막으로 다른 시드를 순차 비교했다. 세 결과의 긴 코와 단순한 피부 표현은 후보를 교체할 만큼 개선되지 않았다. 모델 자체의 성능 한계로 일반화하지 않으며, 현재 작가 태그·텍스트 프롬프트 조합을 반복하는 것은 중단한다. 실제 요청·비용은 각 JSON과 원장에 보존했다. 이번 NAI 차감 0, 누계 5 Anlas.

GPT 방향 시트에서는 앞·사선·측면에 걸쳐 적갈색 단발, 호박색 눈, 작은 코·입과 의상 연결이 대체로 유지됐다. 머리 위 여백을 확보했다. 정면에 약간의 기울기가 남고, 45도/90도는 엄밀한 수치 검증이 없으므로 정투영이나 3D용 완성 자료가 아니다. 한쪽 눈이 앞머리에 일부 가려지는 점도 남아 있다.

현재 전달 검토 묶음은 대표 얼굴, 세 표정, 세 방향 얼굴이다. 클라이언트의 새 외형 승인은 아직 없다. 기존 은발 시안의 긍정 평가는 적갈색 캐릭터 전체 승인으로 확대하지 않는다.
