# 원본 기준 얼굴 시안 v1

8장 전체를 시각 분석한 뒤 얼굴 초상 1장을 제작했다. 성공한 image_gen 요청에 직접 입력한 원본은 첫 묶음 2번(1000076677)과 추가 묶음 1번(1000076669) 두 장이다. 나머지는 얼굴 분석을 지시문에 반영했다. 최초 요청은 참조 수 한도, 다음 요청은 성적 입력 판정으로 거절됐다. 옷을 입은 두 참조로 범위를 좁힌 비노출 얼굴 초상이 생성됐다. NovelAI 호출 및 Anlas 사용은 없다. 거절 요청을 포함한 이미지 도구 할당량 차감은 확인할 수 없다.

검수: 굵은 윗눈선, 작은 코·입, 선명한 머리 하이라이트와 셀 명암으로 기존 시안보다 참고의 표현에 가까워졌다. 머리 기울기·앞머리·배색은 첫 묶음 2번과 유사성이 높다. 현재는 작화 방향 확인용이며 독창적인 캐릭터 정체성 완성으로 보지 않는다. 땋은 머리 좌우가 지시와 반대이고 머리 꼭대기가 잘렸다. 얼굴 방향 검토에는 사용할 수 있으나 설정화로 쓰지 않는다. 재생성 없이 보존했다.
