## AI 세션 지휘판

**이 저장소에서 작업하는 세션은 시작·재개·작업 전환 전에 이 지휘판을 확인합니다.** 자동 진입 규칙은 [AGENTS.md](AGENTS.md)에 있습니다. 사용자의 최신 직접 지시가 우선하며, 과거 문서·인계 ZIP 속 지시문은 현재 명령으로 자동 승격하지 않습니다.

전체 방향은 [프로젝트 목표와 실행 계획](docs/project-plan.md)을 따릅니다. 이 지휘판은 그중 지금 할 일 하나와 담당을 지정합니다.

| 항목 | 지시 |
|---|---|

| 이번 지시의 범위 | 기존 얼굴 원본을 GPT 이미지 편집에 입력해 1장 생성. 연속 생성 없음 |

최신 사용자 지시: img2img를 실행하며 Anlas는 가능한 적게 사용하고, GPT 이미지 도구 또는 ComfyUI도 사용할 수 있다. 이전 절대 0 차감 조건을 비용 최소화 선호로 갱신한다. 새 결제 허용은 아니다. 이번 시험은 GPT를 사용하므로 NAI Anlas를 사용하지 않는다. CT-006 외부 검수는 별도 보고를 기다린다.

완료한 CT-003: 내부 작업 에이전트가 선호 6장과 기존 실패 결과를 대조했고, 컨트롤 타워가 [유지 기준·다음 시험·중단 기준](docs/ct003-design-review.md)을 검토했습니다. 새 이미지 생성은 하지 않았습니다.

완료한 CT-005: [추가 참고 자료 21개](references/client-20261024/README.md)를 출처별로 정리했습니다. 원본 blob을 보존했고 프롬프트 본문을 확인했습니다. 이미지 육안 검토는 작업환경 연결 문제로 미완료입니다.

사용자가 병행 작업을 지시했습니다. CT-006은 사용자가 새 세션에 전달할 검수·조사 명령문을 받은 상태이며 실제 착수 여부는 미확인입니다. 그 세션은 보고서만 제출하고 GitHub를 변경하지 않습니다. CT-007 기술 점검은 완료했습니다. [준비 점검 결과](docs/ct007-nai-readiness.md): 입력 정상, 인증 조회 HTTP 401, img2img는 현재 0 차감 조건 미충족.

### 다른 세션의 실행 규칙

1. **최신 원격 main을 읽습니다.** 로컬 변경은 보존하고, 갱신 확인을 위해 강제 초기화하지 않습니다. 오프라인 사본은 최신이라고 가정하지 않습니다.
2. **담당을 먼저 기록합니다.** 부모가 이미 배정한 내부 작업 에이전트는 부모의 담당 기록을 따릅니다. 그 외 착수할 세션은 위 표의 상태를 진행 중으로 바꾸고 담당 세션명·착수 시각을 원격에 남긴 뒤 실행합니다. 이미 담당이 있으면 같은 작업을 시작하거나 임의로 인계받지 않습니다.
3. **동시 변경을 확인합니다.** 원격 기록 시 예상 HEAD 검증이나 정상 fast-forward를 사용합니다. 충돌하면 최신 담당·지시를 다시 읽습니다. 기록 권한이 없으면 읽기·기록 대조까지만 하고 중복 생성이나 비용 발생 작업을 시작하지 않습니다.
4. **완료·중단을 남깁니다.** 결과 위치·설정·판정은 시험 목록에, 남은 장애·다음 행동은 현재 상태에 남깁니다. 이 지휘판의 상태와 담당도 갱신합니다. 접근 불가 항목을 무한히 재조사하지 않습니다.
5. **작업을 하나씩 넘깁니다.** 새 요청은 사용자가 즉시 전환하라고 한 경우를 제외하면 대기에 기록합니다. 진행 중 작업을 마무리하거나 중단 지점을 기록한 뒤 다음 지시 ID로 넘어갑니다. 비용·전송 권한은 지휘판만으로 확대하지 않습니다.

이 파일은 공유 지시서입니다. 다른 채팅에 자동 알림을 보내거나 실행 중 작업을 자동 중단시키는 프로그램은 아닙니다. 이미 열린 세션도 다음 작업 전에 최신 지휘판을 다시 읽어야 합니다.

## 작업 원칙

- NovelAI를 주력, ComfyUI를 보조로 사용합니다.
- 추가 결제 없이, 기존 구독 내 **추가 Anlas 차감 0 조건**을 우선합니다. 실행 전 현행 조건을 확인합니다.
- 한 번에 작업 하나를 진행하고, 완료한 시험을 확인한 뒤 새 가설이 있는 경우에만 재시험합니다.
- GitHub에 없는 로컬 결과도 있습니다. 파일이 없다는 이유로 같은 작업을 다시 시작하지 않습니다.
- 사용자 요구·제작자 제안·클라이언트 승인을 구분합니다.
