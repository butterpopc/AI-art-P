# 전달 묶음 안내

ZIP은 생성 당시의 묶음입니다. 파일명에 최신·final이 있더라도 클라이언트 최종 승인을 뜻하지 않습니다.

| 파일 | 내용과 상태 |
|---|---|
| [face-review-v4.zip](face-review-v4.zip) | 얼굴·표정·방향 검토 후보. 전체 디자인 승인 전 |
| [fullbody-front-v1.zip](fullbody-front-v1.zip) | 정면 전신 제안. 체형·하의·신발 평가 전 |
| [generated-artwork-library.zip](generated-artwork-library.zip) | 당시 생성 이미지 모음. 이후 로컬 결과 전체를 포함하지 않음 |
| [seorin-client-review-v2.sha256](seorin-client-review-v2.sha256) | 과거 윤서린 패키지의 체크섬 기록. ZIP 실물이 이 경로에 있다고 가정하지 않음 |

이미지 원본은 [artwork](../artwork/), 최신 작업 범위는 [현재 상태](../docs/status.md)에서 확인합니다. 이번 정리에서 ZIP을 재생성하거나 새 결과를 추가하지 않았습니다.
